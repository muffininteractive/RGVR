# 🎮 Wacky Works VR - Build & Deploy

## Quick Start

```bash
# Instalar dependências
npm install

# Desenvolvimento
npm run dev

# Build para produção
npm run build

# Deploy no Vercel
npm run deploy:vercel

# Deploy no GitHub Pages
npm run deploy:github
```
